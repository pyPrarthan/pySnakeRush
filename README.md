# 🐍 pySnakeRush

A classic Snake game built with Python and Pygame — developed in one night as a speed project challenge.

## 🎮 Game Overview

Guide your snake to eat food, grow longer, and survive as long as possible without hitting the walls or yourself. The game speeds up as you eat more, making it progressively harder.

![snake-game-demo](demo.gif)

---

## 🚀 Features

- Classic snake movement mechanics
- Smooth frame-based animation using `pygame`
- Score counter and speed scaling
- Game Over screen with restart option
- Clean object-oriented code structure

---

## 🛠 Tech Stack

- **Python 3**
- **Pygame**

---

## 🔧 Installation & Run

1. Clone the repo:
   ```bash
   git clone https://github.com/pyPrarthan/pySnakeRush.git
   cd pySnakeRush
   ```

2. Install `pygame`:
   ```bash
   pip install pygame
   ```

3. Run the game:
   ```bash
   python main.py
   ```
